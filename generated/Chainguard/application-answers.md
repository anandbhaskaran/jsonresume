## Q1: Why are you interested in working at Chainguard?

I ship AI products (LumApps, and my own things on the side) and I pull hardened base images because I don't want to be the engineer whose sloppy dependency leaked a customer's data. Supply chain is where all my work actually runs. Chainguard is the only team I've come across that treats that seriously and ships things developers use, not another compliance dashboard.

The Agent Skills piece is what pulled me in. I spend my days building agents with MCP tools at LumApps. Bringing that same pattern to supply chain security is a problem I'd genuinely like to work on. The GitHub Actions angle is personal too. I shipped a $337K-saving LLM pipeline on GitHub Actions at Beekeeper, so I know exactly which parts of that stack need to be hardened.

Also, small senior team that ships. I've been interviewing at bigger places and this is the shape of team I'm actually looking for.
